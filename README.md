# BasicAI

Інтерактивний статичний посібник з основ штучного інтелекту для дітей, людей старшого віку та початківців.

## Що вже є

- Великий читабельний інтерфейс українською мовою.
- Ілюстрований перший екран і картки уроків.
- Дубльована навігація зверху, у швидких посиланнях і внизу.
- Простий прогрес у `localStorage`: сайт пам'ятає останній досягнутий рівень.
- Міні-тести, які відкривають наступний рівень після правильної відповіді.
- Блок сценаріїв використання ШІ під час навчання.
- Огляд поширених універсальних AI-сімейств.

## Як відкрити

Відкрийте `index.html` у браузері або розгорніть папку на GitHub Pages.

Для локального сервера можна виконати:

```bash
python3 -m http.server 8080
```

і перейти на `http://localhost:8080`.

## Як додавати уроки

У файлі `script.js` додайте новий об'єкт у масив `lessons`:

```js
{
  id: "new-topic",
  level: 5,
  icon: "5",
  title: "Назва рівня",
  summary: "Коротке пояснення.",
  task: "Міні-дія для учня.",
  quiz: {
    question: "Питання тесту",
    options: ["Варіант 1", "Варіант 2", "Варіант 3"],
    answer: 0
  }
}
```

## Наступні кроки

- Додати окремі сторінки або вкладки для поглиблених уроків.
- Зробити режим "для дітей" і "для дорослих" із різними прикладами.
- Додати прості бейджі за послідовне проходження.
- Оновлювати блок моделей за офіційними джерелами, бо назви та доступність швидко змінюються.
