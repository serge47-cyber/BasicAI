# BasicAI

Практичний інтерактивний посібник "ШІ для всіх" для людей, які хочуть не просто прочитати про штучний інтелект, а одразу навчитися безпечно й корисно його застосовувати.

## Поточна основа розвитку

Канонічний формат проєкту тепер базується на `ai_guide_lessons.html`.

Основний файл для публікації:

```text
index.html
```

Архівна/референсна копія того самого формату:

```text
ai_guide_lessons.html
```

Подальші зміни в інтерфейсі, логіці уроків і методиці варто робити спочатку в цьому 9-урочному форматі. Стара структура `styles.css`, `script.js` і `data/content.json` лишається як матеріал попередньої v2-версії, але більше не є головним напрямом розвитку.

## Що є зараз

- 9 інтерактивних уроків: від різниці між ШІ та Google до безпеки, інструментів, навчання й фейків.
- Вибір стилю навчання замість вікового поділу:
  - "Я дослідник" — для тих, хто любить швидко пробувати й перевіряти.
  - "Я практик" — для тих, хто хоче спокійно застосувати ШІ в конкретних життєвих задачах.
- Покрокове проходження уроків із міні-завданнями, порівняннями, сценаріями й поясненнями.
- Навігація між уроками, позначення пройдених модулів і короткі підсумки після практики.
- Статичний формат, який можна відкрити як файл або опублікувати на GitHub Pages.
- PWA-заготовка: `manifest.webmanifest`, `sw.js` та SVG-іконки.

## Як запустити

Найпростіше відкрити:

```text
index.html
```

Для локальної перевірки через сервер:

```bash
python3 -m http.server 8080
```

Після цього відкрийте:

```text
http://localhost:8080
```

## Принцип розвитку

Фокус проєкту — практичність обраного стилю навчання.

Кожен новий урок або зміна має відповідати трьом питанням:

- Що користувач зможе зробити після цього кроку?
- Чим відрізняється подача для "дослідника" і "практика"?
- Який ризик або типову помилку ми допомагаємо уникнути?

## Найближчі логічні кроки

- Винести зміст 9-урочного формату з HTML у окремий структурований файл, не втрачаючи поточний дизайн.
- Додати практичні шаблони запитів після кожного уроку.
- Додати фінальний блок "Мій перший AI-сценарій" з вибором задачі користувача.
- Додати експорт або друк короткої пам'ятки після проходження.
- Переглянути старі файли `script.js`, `styles.css`, `data/content.json`: або перенести корисні ідеї в основний формат, або прибрати їх з публічної збірки.

## Про AI-інтеграцію

Поточна версія не надсилає дані до зовнішніх AI-сервісів. Якщо додавати реальну інтеграцію з OpenAI або іншим AI API, потрібен невеликий сервер або serverless-функція, щоб не відкривати секретний API-ключ у браузері.
